# BERT Intent Model\n\nThis directory is reserved for storing the fine-tuned BERT model files.\n\nFiles that should be placed here after training or downloading:\n- `pytorch_model.bin` or `model.safetensors` (Model weights)\n- `config.json` (Model configuration)\n- `vocab.txt` (Tokenizer vocabulary)\n- `tokenizer_config.json`\n\n**Note:** Ensure to add large binaries to `.gitignore` to prevent committing them to the repository.\n
